# Brew Board

Интерактивное меню напитков, построенное на Qt6 (C++ + QML). 

## Структура проекта

- `src/` – исходные файлы C++
- `qml/` – QML-файлы и ресурсы
- `cmake/` – дополнительные модули CMake

## Окружение разработки

Проект разрабатывается в NixOS с использованием `nix-shell`. Для входа в окружение выполните:

nix-shell
